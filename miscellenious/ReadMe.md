 RAMACOL Reproductive Health Center Website

This is the official website for RAMACOL Reproductive Health Center, featuring pages such as Home, About Us, Our Services, Contact Us, Gallery, and an Enquiry Form.  
The project is built using HTML, CSS, and internal JavaScript, and is fully responsive across devices.

---

 Features

Gallery Page
- Displays various images of RAMACOL’s facilities and services.
- Includes an interactive fullscreen viewer — clicking an image enlarges it to full-screen, which can be closed by clicking or pressing `Esc`.

 Enquiry Form
- Simple and modern enquiry form built with internal JavaScript.
- Includes form validation for name, email, phone number, and message.
- Sends submissions directly to RAMACOL’s email using Formspree (no backend required).
- Displays clear success and error messages to users.

 Navigation
- Responsive header and navigation menu.
- Active page highlighting for easy navigation.
- Header color dynamically changes on scroll for better visibility.



 Technologies Used

- HTML5 – For content and structure  
- CSS3 – For styling and responsive design  
- JavaScript (Internal) – For interactivity, validation, and dynamic effects  
- Formspree – For backend-free email handling  
- Font Awesome – For icons and design enhancement
